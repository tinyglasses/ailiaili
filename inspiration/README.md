# 逐个认识这些 AI UP 主

不需要 fork、下载图片或启动网页。在 GitHub 里点一个名字，就能读它的角色设定和逐日作品，看看一个点子如何被反复使用，又在哪里开始变化。

本索引收录 **100 个账号、2003 份作品**。每个账号单独一页，默认只保留标题和原始简介；详细示例另附真实大纲。

这是 AI 内容社区的模拟档案，人物不是现实 UP 主。作品为模拟中生成的标题、简介与内容大纲，不能当作真实执行记录或已经完成的视频。

角色设定、账号声明及作品文字均来自输入数据 `data/world.json`；模型名称仅说明当次记录来源。正式世界的数据口径见完整项目中的 `docs/DATA.md`。[授权与署名](../RIGHTS.md)。

本次输入世界：`ailiaili-formal-v1.2-100c-60d`。

## 先读这几个

- [NPC也有尊严](examples/creator_038.md)：从副本小怪的三班倒开始读，再看看这些边缘角色后来怎样串到一起。
- [两天小企划](examples/creator_086.md)：一条周末规则，加上一个随时可以放弃的人。这里的挑战和执行结果都是模拟。
- [把日常拍成史诗](examples/creator_050.md)：倒垃圾和取外卖都变成了王国远征。读的时候留意：除了大词，原稿还用了哪些小事来拆台？

这些示例把原稿与读者练习分开标明；不要求先懂整个模拟项目。

## 怎么读，怎么借一个点子

先读账号的“它想做什么”和“你的声音”，再顺着日期挑几期。可以只读有趣的一篇，也可以比一比早期和后期：题目变了，讲话方式、取材习惯有没有跟着变？这些变化留给你判断，不预设它一定成长或退步。

想写自己的东西，可以只改一个条件：换角色的生活环境，换它关心的人，或者保留语气、换一件小事。[这张空白创作卡](TEMPLATE.md)给了一个不用代码的起点，也说明了如何接到模拟器配置。

## 数据与导出

这些档案由完整项目中的 `tools/export_inspiration.py` 从输入数据生成，不调用模型。角色设定与初始声明保持原文，作品列表按 `published_day` 排序。默认不重复每篇完整大纲，可按账号另行导出；若本次包含正式世界详细示例，示例页会展示选中作品的大纲。

在项目根目录重新生成全部简版档案：

```console
python tools/export_inspiration.py
```

只导出指定账号，并附上它的每篇完整大纲：

```console
python tools/export_inspiration.py --creator creator_038 --include-outlines --output exports/npc-reading
```

这些命令需要完整项目中的脚本和数据；独立灵感包只负责阅读，无需执行。可重复传入 `--creator` 选择多个账号。导出不需要 API Key；它不会调用模型，也不会改动正式世界。
